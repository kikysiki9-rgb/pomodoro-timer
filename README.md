# 🍅 Pomodoro Timer

Простое и стильное веб-приложение Pomodoro Timer для эффективного управления временем и повышения продуктивности.

## Особенности

✅ **Классическая техника Pomodoro** — 25 минут работы, 5 минут перерыва  
✅ **Интуитивный интерфейс** — легко использовать на любом устройстве  
✅ **Отслеживание прогресса** — счётчик завершённых помидоров  
✅ **Уведомления** — браузерные оповещения при смене сессии  
✅ **Адаптивный дизайн** — работает на мобильных и десктопных устройствах  
✅ **Красивая визуализация** — современный фиолетовый градиент

## Быстрый старт

1. Откройте [https://github.com/kikysiki9-rgb/pomodoro-timer](https://github.com/kikysiki9-rgb/pomodoro-timer)
2. Нажмите кнопку "Use this template" или просто откройте `index.html` в браузере
3. Начните использовать!

Или откройте приложение через GitHub Pages:
- После создания репозитория перейдите в Settings → Pages
- Выберите ветку `main` как источник
- Приложение будет доступно по адресу `https://your-username.github.io/pomodoro-timer/`

## Как использовать

1. **Выберите режим** — "Работа" (25 мин) или "Перерыв" (5 мин)
2. **Нажмите "Старт"** — таймер начнёт отсчёт
3. **Пауза** — остановите таймер, если нужно отвлечься
4. **Сброс** — вернитесь на начало текущей сессии
5. **Уведомления** — приложение оповестит вас, когда время истечёт
